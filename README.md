# SideStore-Refresher-Shortcut (Wireguard)

![icon](https://raw.githubusercontent.com/L-port8000/SideStore-Refresher-Wireguard-/refs/heads/main/icon.png)

SideStore Automation Refresh all Apps.

- Moving on "Shortcut"
- ショートカット上で動作します。
- A cron job that refreshes SideStore every 3 days at 3:00 am.
- ３日ごと、午前三時にSideStoreのRefresh all Appsをバックグラウンドで行います。
- Using Wireguard(not LocalDevVPN).
- Wireguardを利用したショートカットです。(LocalDevVPNを使った方法ではありません。)
- Please try using [icon.png](https://raw.githubusercontent.com/L-port8000/SideStore-Refresher-Wireguard-/refs/heads/main/icon.png)
- 是非[icon.png](https://raw.githubusercontent.com/L-port8000/SideStore-Refresher-Wireguard-/refs/heads/main/icon.png)を使ってください。
